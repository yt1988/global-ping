# 决定

产品和技术上定下来的事、试过并放弃的事。按日期倒序，一句话说明「是什么」和「为什么」。面向所有维护者，
所以写通用的理由，不写某个部署的域名、端口和账号。

## 2026-11-08 · 初版

- **18 个地区，和可达性检测同一套。** 站长定的（「全球 18 点，与 reach 统一」）：两个工具对同一个目标报出的
  地区一致，数字才能对照。没有「快速 6 点」这类第二档，一次测试固定 18 个地区次，界面也就不需要范围选择。
- **每个地区固定 16 个包。** Globalping 的 ping 允许 1–16 包，但额度按探测点算：16 包不额外花钱。16 包才有
  足够的变化可看，也是站长要的「逐包可见」。不做 8 包选项，避免两套界面和分享格式。
- **额度显示照抄可达性检测的文案，显示原始地区次，不换算成「还能测几次」。** 站长定的。两个工具的额度口径
  本来就一样（Globalping 的 250 个地区次/小时/IP），同一句话在两边出现才知道是同一件事。
- **东京自有服务器始终显示。** 它是基准线、额度用完时的兜底，也是唯一永远知道真实丢包位置的一条腿；和
  Globalping 的东京探测点对照还能看出两条线路是否一致。它不进全球中位数（一个点会带偏结论）。
- **丢包位置从 `rawOutput` 的 `icmp_seq` 读。** Globalping 的条目不告诉哪一包丢了，但探测点的系统 `ping`
  原文带序号。解析失败时退化成「按回包顺序」并标「位置未知」，绝不编一个位置；东京那条腿天然知道位置。
- **竖线高度以该地区中位数的 1.5 倍为上限、0 起点，不做 min–max 归一化。** 归一化会把 0.1 ms 的正常抖动
  画成满屏大起大落。颜色不按延迟分档：延迟高低取决于距离，好坏只由状态点和结论承担。
- **「有回应 / 没有回应」，不写「通 / 不通」。** 很多主机和防火墙不回 ICMP 但服务正常；说「挂了」是错的。
- **结论和「发现」是确定性规则，页面、分享链接、Worker 标题共用。** 阈值可测试，分享链接冻结当时的结论键，
  以后改阈值不会让旧链接变样。
- **这版不做长尾页。** 首页已经同时收域名和 IP、已经显示 16 包和丢包位置，「Ping 一个 IP」「丢包测试」很容易
  只是同一页换个标题；先上线看真实搜索词，值得做再补（契约反对子页重复首页）。
- **不做对比模式、历史、账号、监控、地图。** 需要的人用命令行或别的工具；地图连线读不出结论。
- **页面不保存结果。** 刷新就没了；要留证据用结果链接（结果全在链接里，不依赖服务端存储）。
- **分享卡片用「结论 + 目标 + 三个数字 + 18 个地区一览」，不画 18 行 16 包小图。** 借鉴可达性检测已验证的
  卡片结构：缩小到聊天预览后，地区名和数字仍然读得出来；16 包小图缩下去就糊了。
- **东京服务的地址放在 `src/config.mjs` 一个常量里，不散落在页面代码里。** 自部署的人改这一处，或者留空：
  留空时页面不显示东京那一行，全球视图照常。业务代码里写死别人的服务器，会让自部署莫名其妙去连我们。
- **东京服务不做结果缓存。** ping 要的是「此刻」的线路状态，缓存会报旧数字；可达性检测缓存是因为它连一次
  端口代价高，这里不是。代价是重复测同一个目标会真的再发包，用「每个访客 20 次/小时、每个目标 60 次/小时、
  全站并发 32」兜住。
- **ICMP 用 `CAP_NET_RAW` 的原始套接字，不要求改全局内核参数。** 非特权 ICMP socket 需要
  `net.ipv4.ping_group_range`，那是机器全局配置；`who` 已有 `CAP_NET_RAW` 的先例。unit 只给这一项能力。
- **ping 的实际实现不写进单元测试，测试注入假的 pinger。** 真 ICMP 需要 Linux 和 `CAP_NET_RAW`，在本机和 CI
  都跑不了；handler、限流、地址校验、JSON 形状用假 pinger 测，真实发包在上线后由外部验证（v4/v6、字段齐全、
  私网拒绝）。
- **不要在 `innerHTML` 里写内联 style，也不要用内联 style 属性。** 页面的 CSP 是 `style-src 'self'`，内联
  `style="--h:…"` 会被浏览器拒掉（16 根竖线全变平）。要用 CSSOM：`element.style.setProperty("--h", …)`。
  这是无头浏览器截图时发现的，静态检查和单测都抓不到。
- **`[hidden]` 要有一条 `display:none !important` 兜底。** 结果区的 `.sec` 自己写了 `display:flex`，会盖掉
  UA 对 `hidden` 的 `display:none`，于是页面一打开就显示一个空的结果区。手机截图发现。
- **截图/真浏览器跑一遍是必需的**：它抓到了 CSP 拦内联样式、分享卡标题用了 i18n 键名（显示成 `loss`）、
  `hidden` 失效、手机头部换行、东京不可用只剩一个「—」这些单测发现不了的问题。
- **分享卡片要用「翻译后的结论句」当标题**：`share()` 的 `name`/`text`/卡片标题都要 `t("v_"+k, …)`，不能把
  verdict 的键名直接传进去（否则卡片上写着 `loss`）。
