# Global Ping 全球 Ping

[English](README.md) · **简体中文**

从全球 18 个地区 ping 一个域名或 IP，每个地区 16 个 ICMP 包：逐包显示延迟和抖动，也能看出丢包发生在第几包。另有我们东京服务器的第二条腿（不花 Globalping 的额度）。

**线上地址：** https://ping.1ms.dog

- **全球视图**：[Globalping](https://globalping.io) 的志愿者探测点分布在 18 个地区（中国大陆电信、联通、移动；香港；中国台湾；东京；韩国；新加坡；印度；澳大利亚；伦敦；法兰克福；俄罗斯；阿联酋；南非；洛杉矶；纽约；圣保罗），每个探针向目标发 16 个 ICMP 回显请求。页面直接调用 Globalping 的接口，所以每位访客花的是自己的免费额度（每个 IP 每小时 250 个地区次；一个地区发 16 包算 1 个地区次，这里测一次用 18 个）。
- **东京视图**：我们自己的服务器发同样的 16 个包。它不花 Globalping 的额度（额度用完时这就是兜底），是唯一永远知道真实丢包位置的视图；和 Globalping 的东京探针对照，还能看出两个网络是不是走同一条路。
- **10 种语言**：English、简体中文、繁體中文、日本語、한국어、Español、Français、Deutsch、Português、Русский。

什么都不存：页面不保存结果，东京服务器不记日志，也从不探测内网或保留地址。值得留下的结果放在结果链接里，链接本身带着整份结果。

## 本地运行

```bash
npm ci
npm run build      # 从 src/ 生成 public/；改完要一起提交 public/
npm run dev        # http://localhost:8787，静态文件加线上同款响应头
npx wrangler dev   # 带 Worker 的本地预览，用来打开 /r/ 结果链接
npm test           # 10 语言文案、测量模型、结果链接编码、public/ 是否为最新
```

页面调用的两个地址：`src/app.js` 里的 `GP`（Globalping）和 `src/config.mjs` 里的 `TOKYO_API`（我们的东京服务器）。自部署时改这两处；CSP 里的 `connect-src 'self' https:` 已经放开。

## 部署

推送 `main` 会部署 Worker（Cloudflare Workers Builds 跑 `npm ci && npm test`，再 `npx wrangler deploy`）。自己托管：`npx wrangler deploy`，然后在 Cloudflare 控制台给 Worker 绑域名。Worker 把 `public/` 当静态文件返回，只在 `/r/<code>`（分享结果给聊天软件生成预览标题）和 404 时运行。

## 服务器

`server/`（Go）是东京视图：`1ms-ping`，一台机器一个程序。它发同样的 16 个包，只需要 `CAP_NET_RAW`，不花 Globalping 的额度，不记日志，也从不探测内网地址。页面在 `src/config.mjs` 的 `TOKYO_API` 找它；没有它（或者留空）时页面不显示东京那一行，全球视图照常。编译、部署和验证见 [server/README.md](server/README.md)。

## 数据与隐私

你填的地址会交给 Globalping（跑全球检测）和东京服务器。请求由你的浏览器直接发出，所以这两方能看到连接来源；我们不收集、不保存测试结果，东京服务器只在内存里数请求次数。结果链接里只有地址和结果，永远不含你自己的 IP。内网、回环、链路本地和组播地址一律不探测。

## 目录结构

```
src/page.html       页面模板
src/app.js          页面：Globalping、东京视图、结论和卡片
src/model.mjs       18 个地区、一个探针的 16 个包、结论和发现（页面、Worker、测试共用）
src/config.mjs      唯一和部署有关的地址：TOKYO_API
src/style.css       设计变量（和其他 1ms.dog 工具一致）和布局
src/code.mjs        结果和链接互转（页面和 Worker 共用）
src/worker.js       Worker：/r/<编码> 返回结论写进标题的页面，其他路径 404
src/i18n/*.mjs      10 种语言的文案；en 是基准
scripts/build.mjs   生成 public/：每种语言一个页面（英文在 /，其他在 /zh-cn/、/ja/ …），sitemap、_headers
scripts/assets.mjs  生成链接预览图
scripts/dev.mjs     本地预览服务器（只有静态文件）
server/             1ms-ping，东京的服务器（Go）：go test ./...；1ms-ping.service 是它的 systemd 配置
```
